01 — คืออะไร

ทำงานจากข้อมูลจริง ไม่ใช่การเดาจากภาพ

โปรแกรมบน Windows บอกอยู่แล้วว่าตัวเองมีอะไรบนจอ — ชื่อของปุ่ม บทบาท สถานะ ตำแหน่ง NamThang อ่านข้อมูลชุดนี้ผ่าน UI Automation แล้วเลือกมาพูดเฉพาะสิ่งที่เปลี่ยน ถ้ารู้ก็บอกว่ารู้ ถ้าเดา ก็ติดป้ายว่าเดา

  • 01

    อ่านจากสิ่งที่โปรแกรมสารภาพ

    ชื่อ ปุ่ม บทบาท สถานะ และตำแหน่ง มาจาก accessibility tree ของระบบ ไม่ใช่การไล่เดาจากพิกเซล จึงไม่ต้องเดาว่าปุ่มนี้คืออะไร

  • 02

    พูดเร็ว และหยุดได้ทันที

    เป้าหมายในแผนคือโฟกัสเปลี่ยนถึงเสียงแรกต่ำกว่า 150 ms วัดจริงได้ 12.9 ms ที่ p95 และกด Ctrl ตัดเสียงได้ทุกเมื่อ ไม่ต้องรอให้ประโยคจบ

  • 03

    อยู่ร่วมกับ screen reader ไม่ใช่แข่ง

    คนที่ใช้ NVDA หรือ JAWS อยู่แล้ว ยังใช้ตัวเดิมได้ NamThang เสริมในจังหวะที่การอ่านทั้งหน้าไม่ทัน และไม่แย่งคีย์ของคุณ

  • 04

    ค่าเริ่มต้นคือไม่ส่งอะไรออกไป

    เสียงพูดสร้างในเครื่องด้วย OneCore ไม่มีข้อมูลออกจากเครื่อง ไม่มี analytics และไม่มีบัญชีให้สมัคร

ยังไม่เสร็จ อยู่ในแผนแต่ยังไม่ทำ: สั่งด้วยชื่อแล้วตรวจว่าจอเปลี่ยน · อ่านผลเทสต์ใน terminal · สะพานต่อไปยังเบราว์เซอร์ · คำสั่งเสียง · รู้จำภาพสำหรัยแอปที่ไม่เปิด accessibility

03 — คีย์ที่ใช้จริงวันนี้

คีย์ที่จำแล้วใช้ได้เลย

ไม่มีเมนูให้ไล่หา ทุกอย่างอยู่บนคีย์บอร์ด และทุกปุ่มทำงานแม้โฟกัสอยู่ในโปรแกรมอื่น ถ้าคีย์ถูกโปรแกรมอื่นจองไปแล้ว NamThang จะบอกออกเสียงว่าใช้ไม่ได้ ไม่เงียบหายไปเฉย ๆ

Ctrl
ตัดเสียงทันที — กดครั้งเดียวตอนกำลังพูด ปล่อยแล้วใช้ต่อได้ ไม่ต้องรอประโยคจบ
Ctrl + Alt + W
ฉันอยู่ตรงไหน — บอกหน้าต่างและตำแหน่งที่โฟกัสอยู่ตอนนี้
Ctrl + Alt + ↓ / ↑
ชิ้นถัดไป / ก่อนหน้า — เดินทีละรายการในหน้าต่างที่โฟกัสอยู่
Ctrl + Alt + H
หัวข้อถัดไป — กระโดดข้ามเนื้อหาไปทีละหัวข้อ
Ctrl + Alt + K / B / E
ลิงก์ / ปุ่ม / ช่องกรอกถัดไป — ตามชนิดของคอนโทรลที่หา
Ctrl + Alt + A
อ่านต่อเนื่อง — อ่านจากตรงนี้จนจบหน้าต่าง
Ctrl + Alt + V
ประวัติคำพูด — ย้อนฟังสิบบรรทัดล่าสุดที่เพิ่งพูดไป
Ctrl + Alt + F1
ช่วยคีย์ — กดปุ่มไหนก็บอกชื่อปุ่ม กดอีกครั้งเพื่อปิด
Ctrl + Alt + S
หยุดเสียง (ปุ่มสำรอง) — ถ้าถูกโปรแกรมอื่นใช้อยู่ จะได้ยินคำบอกว่าไม่ได้จองคีย์นี้
Ctrl + Alt + Q
ออกจากโปรแกรม — ปิดแล้วไม่มีอะไรค้างในเครื่อง

ปุ่มอ่านขยับ “ตำแหน่งอ่าน” ไม่ใช่โฟกัสของคุณ — ไม่มีการกดหรือพิมพ์แทน โปรแกรมที่ใช้อยู่จึงทำงานปกติ

04 — ข้อจำกัด

สิ่งที่มันยังทำไม่ได้

เครื่องมือช่วยเหลือที่โกหกเรื่องขีดจำกัดของตัวเองคือเครื่องมือที่อันตราย ต่อไปนี้คือสิ่งที่ NamThang ไม่ทำ หรือยังทำไม่ได้ ณ วันนี้

  • ยังไม่มีเวอร์ชันให้ใช้จริง เป็น pre-alpha ยังไม่ผ่านการทดสอบกับผู้ใช้จริงในวงกว้าง
  • เข้าไม่ได้: หน้า sign-in และหน้าต่าง UAC สองจุดนี้ต้องใช้ screen reader ของระบบ เพราะโปรแกรมทั่วไปถูกกันออกโดยเจตนา
  • เกมและแอปที่ไม่เปิด accessibility ต้องใช้การรู้จำภาพ ซึ่งอาจผิด และจะถูกติดป้ายว่า “เดา” ให้คุณรู้ตัว
  • Windows เท่านั้น ไม่มีแผนสำหรับ Linux หรือ macOS
  • ยังไม่วัดครบ VS Code และ Notepad วัดไม่ได้ในรอบล่าสุด และเหตุการณ์โฟกัสราว 2% ที่ระบบไม่ส่งมา ยังต้องวัดซ้ำอีกหลายพันครั้ง
  • ฟีเจอร์ในแผนยังไม่เกิด สั่งด้วยชื่อแล้วตรวจว่าจอเปลี่ยน · อ่านผลเทสต์ใน terminal · สะพานต่อไปยังเบราว์เซอร์ · คำสั่งเสียง และรู้จำภาพสำหรับแอปที่ไม่เปิด accessibility

05 — ความเป็นส่วนตัว

ค่าเริ่มต้นคือไม่มีอะไรออกจากเครื่อง

เสียงพูดถูกสร้างในเครื่องด้วย OneCore ของ Windows ไม่ต้องต่อเน็ต ไม่ต้องสมัครบัญชี และไม่มี analytics ในตัวโปรแกรม

ถ้าคุณเลือกเปิดเสียงออนไลน์เอง หน้าตั้งค่าจะบอกตรง ๆ ว่าจะส่งข้อความอะไรออกไปที่ไหน และปิดกลับได้ทุกเมื่อ — ไม่มีการเปิดให้เองแบบเงียบ ๆ

หน้านี้ก็ไม่มี tracker เช่นกัน ไม่มีคุกกี้ ไม่มีการเรียก analytics ใด ๆ

06 — ติดตั้ง

ติดตั้งแล้วใช้ได้ในไม่กี่นาที

ตัวติดตั้งไฟล์เดียว ติดตั้งให้ผู้ใช้คนปัจจุบัน ไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ และไม่ต้องลง .NET เพิ่ม เพราะตัวสร้างเสียงถูกฝังมาให้แล้ว

  1. 1
    ดาวน์โหลด

    กดปุ่มดาวน์โหลด ได้ไฟล์เดียวชื่อ NamThang-0.1.0-setup.exe ขนาด 111.8 MB ที่อื่นไม่ใช่ตัวทางการ

  2. 2
    ติดตั้ง

    ดับเบิลคลิกแล้วทำตามหน้าจอ ใช้เวลาราวหนึ่งนาที และไม่ต้องรีสตาร์ต ถ้าขึ้นหน้า Windows protected your PC ให้กด ข้อมูลเพิ่มเติม แล้ว เรียกใช้ต่อไป เพราะไฟล์ยังไม่ได้ลงนามดิจิทัล

  3. 3
    เริ่มใช้

    เปิดจากเมนู Start ถ้าใช้ NVDA อยู่ให้ปิดก่อน เพื่อไม่ให้เสียงพูดทับกัน แล้วกด Ctrl + Alt + W เพื่อฟังว่าตอนนี้อยู่ตรงไหน · Ctrl หยุดพูด · Ctrl + Alt + Q ออก

07 — สัญญากับผู้ใช้

ฟรีตลอดไป ตรวจสอบได้ทุกบรรทัด

ไม่มีรุ่นเสียเงิน ไม่มีฟีเจอร์ที่ถูกล็อกไว้ขาย และไม่มีอะไรที่คุณตรวจสอบเองไม่ได้ ข้อความทางกฎหมายฉบับเต็มอยู่ในไฟล์ LICENSE

  • ใช้ฟรีทุกคน

    ผู้พิการทางสายตาไม่ต้องจ่ายเงินเลย และจะไม่มีรุ่นที่ต้องจ่ายในอนาคต

  • โค้ดเปิดให้อ่านทั้งหมด

    อ่านได้ทุกบรรทัดเพื่อการศึกษา ตรวจสอบ หรือเรียนรู้ — เป็น source-available ไม่ใช่ open source ตามนิยาม

  • แจกต่อได้ ไม่เก็บเงิน

    มูลนิธิ โรงเรียน หรือหน่วยงานสามารถแจกตัวทางการที่ไม่ถูกแก้ได้

  • ห้ามขายและห้ามรีแบรนด์

    ห้ามรวมในสินค้าที่เก็บเงิน ห้ามแจกเวอร์ชันที่แก้ หรือลบชื่อผู้สร้าง
